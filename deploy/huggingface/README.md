# Review Analyzer API

FastAPI backend for the [Review Discovery Engine](https://github.com/ankitashok15/Review-Analyzer).

Copy this file to the **root of your Hugging Face Space** as `README.md`.

Set these secrets in Space Settings:

- `DATABASE_URL` — Neon connection string
- `GOOGLE_API_KEY`
- `ADMIN_API_KEY`
- `CORS_ORIGINS` — include your GitHub Pages URL and this Space URL
